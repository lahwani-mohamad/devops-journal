# Linux Cheatsheet

1. `pwd` - Shows the directory I am currently working in.
2. `ls` - Lists the files and folders in a directory.
3. `cd` - Moves me from one directory to another.
4. `mkdir` - Creates a new directory.
5. `touch` - Creates an empty file if it does not exist.
6. `cat` - Displays the contents of a file in the terminal.
7. `cp` - Copies a file or directory to another location.
8. `mv` - Moves or renames files and directories.
9. `rm` - Removes files I no longer need.
10. `grep` - Searches for matching text inside files.
