# Git Cheatsheet

1. `git init` - Creates a new Git repository.
2. `git status` - Shows the current state of my files.
3. `git add` - Adds changes to the staging area.
4. `git commit` - Saves staged changes in Git history.
5. `git log` - Shows the history of commits.
6. `git branch` - Lists or manages branches in a repository.
7. `git switch` - Moves between branches.
8. `git merge` - Combines changes from another branch.
9. `git push` - Uploads local commits to a remote repository.
10. `git pull` - Downloads and integrates changes from a remote repository.
